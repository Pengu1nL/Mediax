## 二、方案设计

### 2.1 新增 Brief 对照面板

DraftEditor 右侧栏**顶部**新增专用对照面板：

```
┌──────────────────────────────────────────┐
│  📋 任务 Brief                             │
│                                           │
│  发布渠道：微信公众号     内容类型：图文     │
│  ───────────────────────────────          │
│                                           │
│  发布秋季招生主视觉海报，突出融合教育理念     │
│  和临港校区环境，配合招生简章下载入口。       │
│                                           │
│  执行要求：                                │
│  • 使用品牌视觉识别规范                     │
│  • 包含招生简章下载二维码                   │
│                                           │
│  调研参考：                                │
│  调研小红书教育类热门话题和标签              │
└──────────────────────────────────────────┘
```

### 2.2 设计要点

- **位置**：右侧栏第一个面板（最重要，审核时第一眼看到）
- **样式**：与周围面板区分——`bg-lifted-cream` + 左侧彩色边框（`border-l-4 border-signal-orange`）
- **紧凑布局**：渠道+类型一行并排，执行要求用列表，调研参考用斜体
- **可折叠**：如果用户确认无误，可收起（但仍默认展开）
- **永远显示**：只要有 task 就显示，不区分 Agent 生成还是手动创建

### 2.3 字段展示逻辑

| 字段 | 展示条件 | 格式 |
|------|---------|------|
| 发布渠道 + 内容类型 | 有值即展示 | 一行并排，小型标签 |
| Brief | 有值即展示 | 正文段落，font-medium |
| 执行要求 | `requirements.length > 0` | 列表 dots |
| 调研参考 | `researchInstructions` 非空 | 斜体小字 |

所有字段为空时面板不显示。

### 2.4 右侧栏面板顺序

```
DraftEditor 右侧栏：

1. 📋 任务 Brief（对照面板）        ← 新增，最重要
2. 草稿信息（状态、更新时间、计划）   ← 已有
3. Agent 来源 / 关联上下文          ← 已有，简化
4. 配图预览                        ← 已有
5. 审核操作                        ← 已有
```

### 2.5 简化已有面板

Brief 提取到顶部对照面板后，"Agent 来源"和"关联上下文"面板中**移除 Brief 展示**（避免重复），仅保留 Agent 来源、内容类型、链接按钮。
