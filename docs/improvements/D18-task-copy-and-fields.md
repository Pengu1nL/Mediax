## 二、方案设计

### 2.1 任务复制

TaskRow 三点菜单增加"复制"：

```
编辑
复制        ← 新增
────────
删除
```

**复制逻辑：**
- 打开创建弹窗，预填源任务所有字段
- 标题自动追加 " (副本)"
- `schedule` 清空（用户应重新设定调度时间）
- 提交时创建全新任务（新 id，新 planId 不变）

### 2.2 补齐 requirements

表单新增"执行要求"（Brief 和渠道之间）：

```
执行要求
┌──────────────────────────────────────────────┐
│ 使用品牌视觉规范, 包含二维码, 字数不超过1000     │
└──────────────────────────────────────────────┘
逗号分隔，每项为一个要求
```

- 单行文本输入，逗号分隔
- 提交 → `split(',').map(trim).filter(Boolean)` → `string[]`
- 编辑回显 → `requirements.join(', ')`

### 2.3 补齐 researchInstructions

表单新增"调研参考"（补充说明下方）：

```
调研参考
┌──────────────────────────────────────────────┐
│ 参考竞品A的公众号风格，调研近期行业热点关键词    │
└──────────────────────────────────────────────┘
```

- textarea 2 行，自由文本

### 2.4 Agent 效果

```
System prompt:
【创作要求】
- 使用品牌视觉规范
- 包含二维码
- 字数不超过1000

User prompt:
参考以下调研信息：参考竞品A的公众号风格，调研近期行业热点关键词

请为以下任务创作内容：
...
```

用户首次能够直接控制 Agent 的两个关键 prompt 字段。
