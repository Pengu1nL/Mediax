## 二、方案设计

### 2.1 快速预览弹窗

每个草稿卡片新增"预览"按钮。点击弹出阅读视图：

```
┌──────────────────────────────────────┐
│              ✕                       │
│                                      │
│  [微信公众号] · 图文 · 可发布          │
│                                      │
│  ┌─ 标题 ───────────────────────────┐│
│  │ 标题标题标题                      ││
│  └──────────────────────────────────┘│
│                                      │
│  ┌─ 正文 ───────────────────────────┐│
│  │                                  ││
│  │ （渲染后的富文本内容预览）         ││
│  │                                  ││
│  │                                  ││
│  └──────────────────────────────────┘│
│                                      │
│  [编辑]            [关闭]             │
└──────────────────────────────────────┘
```

- 居中弹窗，`max-w-2xl`，可滚动
- 标题大字展示
- 正文完整渲染（D24 后为 HTML，D24 前为纯文本）
- 底部快捷操作："编辑"（跳转编辑器）/ "关闭"

### 2.2 列表卡片改造

在现有操作区增加"预览"按钮：

```
                              预览 →  编辑 →  删除
```

三个操作从左到右排列，"预览"最常用放在第一位。

### 2.3 交互细节

- 点击卡片标题/摘要仍跳转编辑器（保持现有行为）
- 点击"预览"按钮打开弹窗
- 弹窗顶部 `Esc` 可关闭
- 点击遮罩区关闭
- 弹窗内按 `E` 快捷键 → 进入编辑器
- 弹窗内容使用 D24 的 TipTap 只读模式渲染（不可编辑）
