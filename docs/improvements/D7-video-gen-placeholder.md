# D7：视频生成占位体验优化

> 状态：方案已产出  
> 涉及范围：前端  
> 依赖：无

---

## 一、问题回顾

| # | 问题 | 严重度 |
|---|------|--------|
| 1 | 视频生成区块整体 `opacity-60`，看起来像功能损坏，而不是"即将上线" | 中 |
| 2 | VideoForm 处于半残状态：Provider 可选，但 Model/Key/URL 全部 disabled | 中 |
| 3 | "即将支持"标签模糊，未说明视频生成的功能价值 | 低 |
| 4 | `videoGen` 在后端完全没有实现代码，Provider 选择无意义 | 低 |

---

## 二、方案设计

### 2.1 整体思路

将"残废表单"替换为**精心设计的"即将上线"预告卡片**，让用户感知为有计划的功能而非已损坏的功能。

### 2.2 交互设计

#### 当前（问题态）

```
┌──────────────────────────────────────┐  opacity-60
│ 🎬 视频生成                           │
│ 即将支持 · 预留配置                    │
│ ┌──────────────────────────────────┐ │
│ │ Provider: [OpenRouter ▼]         │ │  enabled
│ │ Model:    [即将支持]  disabled    │ │
│ │ API Key:  [即将支持]  disabled    │ │
│ │ Base URL: [默认值]    disabled    │ │
│ └──────────────────────────────────┘ │
└──────────────────────────────────────┘
```

#### 改进后

```
┌──────────────────────────────────────────────┐
│  🎬  视频生成                                 │
│                                               │
```

### 2.3 设计要点

- **全不透明度**，正常卡片样式，不再 `opacity-60`
- 内层区域使用**虚线边框**（`border-2 border-dashed border-zinc-200 rounded-3xl`），与 LLM/图片生成的实线表单形成视觉区分
- header 图标用 `Video` 保持语义一致，但颜色改为正常
- 文案描述功能价值而非技术细节（不提"预留配置"）
- 文字居中对齐，使用 `text-zinc-400` 等低强调色

### 2.4 技术变更

- 删除 `VideoForm` 组件（`Settings.tsx:77-101`）
- 删除 `VideoGenConfig` 导入（`Settings.tsx:5`）
- section 移除 `opacity-60`
- 保留 `videoGen` 类型定义、默认值、seed data（为未来实现保留数据结构）
