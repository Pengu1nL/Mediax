# D17：渠道与内容类型自定义

> 状态：方案已产出

## 一、问题回顾

| # | 问题 | 严重度 |
|---|------|--------|
| 1 | 发布渠道仅 5 个固定选项，无"其他"自定义 | 中 |
| 2 | 内容类型仅 5 个固定选项，无"其他"自定义 | 中 |
| 3 | 不同品牌内容策略差异大，固定选项无法满足长尾需求 | 中 |

`channel` 和 `contentType` 在类型系统中均为 `string`，Agent 仅将它们作为文本注入 LLM prompt，自定义值完全兼容。

---

## 二、方案设计

### 2.1 统一交互模式

与 D3（行业选择灵活化）相同的 pattern：预设选项 + "其他（自定义）"触发文本输入。

**发布渠道：**

```
正常态：
┌─────────────────────────────────┐
│ 微信公众号                   ▼   │
└─────────────────────────────────┘

选择"其他（自定义）"时：
┌─────────────────────────────────┐
│ 其他（自定义）               ▼   │
└─────────────────────────────────┘
┌─────────────────────────────────┐
│ 请输入发布渠道                   │
└─────────────────────────────────┘
```

**内容类型：** 同上结构。

### 2.2 预设选项

**发布渠道**（保持现有 5 个 + 自定义）：

```
微信公众号 / 小红书 / 抖音 / 视频号 / 官方博客 / 其他（自定义）
```

**内容类型**（保持现有 5 个 + 自定义）：

```
图文 / 短视频 / 直播 / 长文章 / 海报 / 其他（自定义）
```

### 2.3 交互规则

| 场景 | 行为 |
|------|------|
| 选择预设选项 | 直接使用选中值，隐藏自定义输入框 |
| 选择"其他（自定义）" | 下方出现文本输入框，光标自动聚焦 |
| 预设 → 其他 | 自定义输入框出现，为空状态 |
| 其他 → 预设 | 自定义输入框隐藏，输入内容保留 |
| 编辑已有任务回显 | 如果值不在预设列表中 → 下拉选中"其他"，输入框显示原值 |
| 提交 | 预设选项 → 保存选项文本；自定义 → 保存输入框文本 |

两个字段各有独立的自定义 state，共享同样的交互逻辑。

## 四、验收标准

- [ ] 发布渠道下拉包含 5 个预设 + "其他（自定义）"
- [ ] 内容类型下拉包含 5 个预设 + "其他（自定义）"
- [ ] 选择"其他"时下方出现文本输入框
- [ ] 自定义值正确保存为 channel / contentType
- [ ] 编辑已有任务时自定义值正确回显
- [ ] 提交时自定义值通过必填校验（非空）
- [ ] preset → custom → preset 切换数据不丢失
