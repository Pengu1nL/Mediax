## 二、死字段清理

### 发现

以下 6 个 Plan 字段在代码库中**零引用**（Agent 不用、前端不展示），仅存在于类型定义和 seed data：

```
objective, audience, channels, successMetrics, automationLevel, reviewPolicy
```

### 清理后

```typescript
interface Plan {
  id: string;
  title: string;
  status: PlanStatus;
  startDate: string;
  endDate: string;
  category?: string;
  brandId?: string;
}
```

同步清理 `src/constants.ts` 和 `server/store.ts` 中 seed data 的对应字段。

## 三、计划模板

### 3.1 模板定义

创建弹窗表单上方增加模板快速选择：

| 模板 | 预填标题 | 预填分类 | 日期建议 |
|------|---------|---------|---------|
| 产品发布 | "产品发布计划" | "产品发布" | 未来 2 周 |
| 活动营销 | "活动营销计划" | "活动营销" | 未来 2 周 |
| 日常内容 | "日常内容日历" | "日常运营" | 未来 1 周 |

### 3.2 适用场景

| 模板 | 场景举例 |
|------|---------|
| 产品发布 | 新品上市、产品迭代、功能发布上线 |
| 活动营销 | 节日促销、品牌日、校庆、行业峰会 |
| 日常内容 | 每周固定发布、公众号日更、常规内容维护 |

### 3.3 交互

```
┌──────────────────────────────────────────┐
│  创建发布计划                              │
│                                           │
│  快速模板：                                │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐  │
│  │ 🚀       │ │ 🎉       │ │ 📅       │  │
│  │ 产品发布  │ │ 活动营销  │ │ 日常内容  │  │
│  └──────────┘ └──────────┘ └──────────┘  │
│                                           │
│  ── 或手动填写 ──                          │
│  计划标题：[                          ]    │
│  ...                                      │
└──────────────────────────────────────────┘
```

- 点击模板卡片 → 自动填入标题、分类、时间段
- 用户可修改任意预填内容
- 不选模板直接手动填也行
- 模板数据为前端常量，不涉及后端

## 四、批量操作

### 4.1 批量模式

计划卡片左上角新增 checkbox：
- 点击 checkbox 进入批量模式
- 工具栏切换为："已选 3 项 | [批量归档] [批量删除] [取消]"

### 4.2 操作确认

| 操作 | 确认文案 |
|------|---------|
| 批量归档 | "确定将 3 个计划标记为已完成？" |
| 批量删除 | "确定删除 3 个计划？关联任务会移除，草稿保留但不再挂在计划下。" |

确认后逐个调用 `updatePlan` / `deletePlan`。

### 4.3 交互细节

- `Escape` 键退出批量模式
- 点击卡片本身仍跳转详情页
- 至少选中 1 项时操作按钮才可用
- 操作完成后自动退出批量模式
