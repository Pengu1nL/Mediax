## 二、方案设计

### 2.1 入门清单

Dashboard 顶部（hero 区下方）新增"入门指引"卡片，自动检测各步骤完成状态：

```
┌──────────────────────────────────────────────────┐
│  🚀  入门指引                                      │
│                                                   │
│  ✅  定义品牌             Mediax · 传媒             │
│  ✅  配置 AI 接口          DeepSeek V4 Pro          │
│  ❌  上传品牌素材           0 条知识条目              │
│  ❌  创建发布计划           0 个计划                 │
│  ○  创建并执行任务          —                       │
│  ○  完成首次发布            —                       │
│                                                   │
│  完成 2/6 步              [收起]                    │
└──────────────────────────────────────────────────┘
```

### 2.2 步骤检测逻辑

| 步骤 | 检测条件 | 链接 |
|------|---------|------|
| 定义品牌 | `brand.setupComplete === true` | `/brand` |
| 配置 AI 接口 | `config.llm.apiKey` 非空 | `/settings` |
| 上传品牌素材 | `knowledgeEntries.length > 0` | `/knowledge` |
| 创建发布计划 | `plans.length > 0` | `/plans` |
| 创建并执行任务 | `planTasks.some(t => t.linkedDraftIds?.length > 0)` | `/plans` |
| 完成首次发布 | `publishRecords.length > 0` | `/drafts` |

### 2.3 交互设计

- **完成步骤**：绿色对勾 + 灰色文字（表示已完成）
- **当前建议步骤**：第一个未完成的步骤使用橙色高亮（引导用户点击）
- **未完成步骤**：空心圆 + 灰色文字
- **不可用步骤**（前置步骤未完成）：更浅的灰色，不可点击
- 每个步骤行可点击，跳转到对应页面
- "收起"按钮将清单折叠为一行（"入门指引 ▸ 完成 2/6"）
- 全部 6 步完成后清单消失，Dashboard 恢复正常

### 2.4 显示时机

- 品牌设定未完成 → 始终显示（引导完成 Onboarding）
- 全部完成 → 不显示
- 收起后 → 下次进入 Dashboard 默认展开（直到完成 4 步以上）
