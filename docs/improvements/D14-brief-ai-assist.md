## 一、问题回顾

| # | 问题 | 严重度 |
|---|------|--------|
| 1 | Brief 是 Agent 生成质量的决定性因素，但输入框是裸 `<textarea>` | 高 |
| 2 | 无 AI 辅助优化，用户不知道该写什么、怎么写 | 高 |

| 4 | 无字数/质量反馈 | 低 |

## 二、方案设计

### 2.1 AI 优化按钮

Brief 标签右侧增加"AI 优化"按钮：

```
任务 Brief *                          [✨ AI 优化]
┌──────────────────────────────────────────────┐
│  （用户输入 brief 草稿）                       │
└──────────────────────────────────────────────┘
 150 字 · 包含目标受众、核心信息 ✓
```

**交互流程：**
1. 用户输入初稿（或留空，基于任务标题推断）
2. 点击"AI 优化"→ 按钮 loading 态
3. AI 基于标题 + 渠道 + 内容类型 + 当前文本生成优化版
4. 优化结果填入 textarea，带短暂高亮闪烁
5. 可继续手动编辑或再次优化

### 2.2 实时质量反馈

textarea 下方显示：

| 字数 | 提示 |
|------|------|
| < 30 字 | "Brief 过短，建议补充目标受众和核心信息点" |
| 30-80 字 | "Brief 基本完整，可继续完善" |
| > 80 字 | "内容充足，AI 优化可进一步提升质量" |

### 2.3 快速模板

textarea 上方放置模板 chips：

```
模板： [产品发布] [活动营销] [品牌宣传]
```

| 模板 | 预填内容 |
|------|---------|
| 产品发布 | "发布{产品名}，突出核心功能与差异化价值，目标受众为{受众}，语言简洁有吸引力，引导点击/下载。" |
| 活动营销 | "推广{活动名}，传达活动亮点和参与方式，目标受众为{受众}，营造紧迫感和参与欲望。" |
| 品牌宣传 | "强化品牌{核心定位}认知，通过{内容角度}建立专业形象，语言{语气风格}，面向{受众}。" |

模板中 `{...}` 占位符高亮显示，引导用户替换为具体内容。模板为前端常量。

### 2.4 API

```
POST /api/tasks/suggest-brief
```

**请求体：**
```json
{
  "title": "公众号预热头图发布",
  "channel": "微信公众号",
  "contentType": "图文",
  "brief": "可选，当前已输入的草稿"
}
```

**响应体：**
```json
{ "brief": "优化后的完整 brief..." }
```

**Prompt 设计：**
- System: 内容运营 Brief 撰写专家，要求输出 100-200 字结构化 brief
- User: 任务标题 + 渠道 + 类型 + 当前草稿（如有）
- 不做数据持久化

### 2.5 textarea 扩展

- `rows` 从 3 改为 5
- 底部显示实时字数统计
