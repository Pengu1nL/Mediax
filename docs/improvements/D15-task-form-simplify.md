## 二、方案设计

### 2.1 移除状态字段

**问题：** 创建任务时展示 6 种状态选项，但只有"草稿"在创建时有意义。其他状态（排队中/待审核/已批准/已发布/已取消）是任务执行生命周期中的状态，不应在创建表单中出现。

**方案：** 创建时自动设为 `draft`，不在表单中展示。编辑时可保留，变为简单展示（非 editable select），状态通过任务操作按钮流转。

### 2.2 审核策略自动继承品牌默认值

**问题：** 用户在 Onboarding 中已经选择过一次 `defaultReviewPolicy`，但创建每个任务时又要重新选。PlanDetails 甚至没有引入 `brand`。

**方案：**
- 从 `useAppStore` 中引入 `brand`
- `defaultTaskForm.reviewPolicy` 从 `brand.defaultReviewPolicy` 初始化
- 保留字段在表单中（允许单任务覆盖品牌默认值），但初始值与品牌一致
- 编辑已有任务时保持原值不变

### 2.3 精简后的表单

| 字段 | 必填 | 变更 |
|------|------|------|
| 任务名称 | ✅ | 不变 |
| 任务 Brief | ✅ | D14 AI 辅助 |
| 发布渠道 | ✅ | 不变 |
| 内容类型 | ✅ | 不变 |
| 执行类型 | ✅ | 不变 |
| 调度时间 | ✅ | D16 简化循环调度 |
| 补充说明 | 否 | 不变 |
| ~~状态~~ | — | **从创建表单移除**，自动 `draft` |
| 审核策略 | 否 | **初始值从 brand 继承**，可覆盖 |

表单从 9 个字段减为 7 个（含调度），状态字段移除，审核策略自动填入。
