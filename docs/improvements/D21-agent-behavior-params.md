# D21：Agent 行为参数化定制

> 状态：方案已产出  
> 涉及范围：前端 + 后端  
> 依赖：D17（自定义渠道后尺寸匹配需特别处理）、D20（Prompt 预览反映参数影响）

---

## 一、问题回顾

| # | 问题 | 严重度 |
|---|------|--------|
| 1 | RunAgentDialog 仅提供配图开关和尺寸，用户无法影响内容生成行为 | 高 |
| 2 | 无法指定内容长度（短文案 vs 长文章） | 中 |
| 3 | 无法提供额外指令细调 Agent 行为 | 中 |
| 4 | 无法临时覆盖品牌默认语气 | 低 |
| 5 | 图片尺寸推荐未覆盖所有平台×内容类型组合 | 中 |

---

## 二、方案设计

### 2.1 新增 3 个行为参数

RunAgentDialog 增加"高级选项"可展开区域：

```
┌──────────────────────────────────────┐
│  启动 Agent 执行                      │
│                                      │
│  任务：xxx         平台：微信公众号    │
│  推荐尺寸：900×383（头图 2.35:1）     │
│                                      │
│  [✓] 自动生成配图                     │
│  图片尺寸：[900x383       ]          │
│                                      │
│  ── 高级选项 ──                 [展开]│
│  ┌────────────────────────────────┐  │
│  │ 内容长度：                      │  │
│  │  [简洁] [标准] [详细]           │  │
│  │                                │  │
│  │ 语气覆盖（可选）：              │  │
│  │  [临时覆盖品牌默认语气...]       │  │
│  │                                │  │
│  │ 额外指令（可选）：              │  │
│  │  [追加到 prompt 的指令...]      │  │
│  └────────────────────────────────┘  │
│                                      │
│  [取消]              [确认执行]       │
└──────────────────────────────────────┘
```

### 2.2 参数详情

| 参数 | 类型 | 默认 | 注入效果 |
|------|------|------|---------|
| 内容长度 | 单选 | 标准 | user prompt 追加字数指令 |
| 语气覆盖 | 文本 | 空 | 非空时替换 system prompt 中的品牌语气 |
| 额外指令 | 文本 | 空 | 追加到 user prompt 末尾 |

**内容长度映射：**

| 选项 | LLM 指令 |
|------|---------|
| 简洁 | "生成简洁短文案，100-200字" |
| 标准 | "生成标准长度内容，300-500字" |
| 详细 | "生成长文章，800-1500字，结构完整" |

### 2.3 平台 × 尺寸自动匹配

**问题：** 当前 `platformImageSizes.ts` 仅覆盖 4 个平台 × 少数内容类型。D17 引入自定义渠道后，新渠道无法匹配尺寸。

**扩充平台尺寸数据库：**

**自定义渠道处理：**
- 用户使用 D17 的自定义渠道 → 尺寸匹配 fallback 到 `DEFAULT_PRESET`（1024×1024 通用方形）
- RunAgentDialog 显示"未匹配到平台推荐尺寸，使用通用方形"
- 用户可手动修改尺寸

**RunAgentDialog 中展示：**
- 平台名 + 推荐尺寸 + 比例说明（如"头图 2.35:1"）
- 配图开关打开时，尺寸输入框自动填入匹配值
- 手动修改后不再自动匹配

### 2.4 后端适配

使用统一接口 `AgentGenerationOptions`（定义见 [`_shared-agent-options.md`](_shared-agent-options.md)）：

- `buildSystemPrompt(context, options)`：`toneOverride` 非空时替换品牌语气行
- `buildUserPrompt(context, options)`：`contentLength` 注入字数指令，`extraInstructions` 追加到末尾
- `AgentRun.generationOptions` 存档完整参数，供 D26 重新生成时复用

### 2.5 多候选版本

本次不做。需改动 LLM 输出格式、解析逻辑、Draft 存储，工程量较大。标记为未来增强。

## 四、验收标准

- [ ] RunAgentDialog 可展开"高级选项"

- [ ] 自定义渠道 fallback 到通用方形 + 提示

- [ ] 默认参数时 Agent 行为与之前一致
