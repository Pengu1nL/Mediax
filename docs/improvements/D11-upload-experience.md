## 二、方案设计

### 2.1 拖拽上传

KnowledgeBase 页面作为全局 drop zone：

**拖拽进入时：** 全页面覆盖半透明遮罩 + 居中提示区

```
┌──────────────────────────────────────────┐
│  （半透明遮罩 + 背景可见知识库列表）        │
│                                           │
│         ┌ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐            │
│         │                    │            │
│         │   📂 松开以添加素材  │            │
│         │                    │            │
│         │  支持图片（PNG/JPG/ │            │
│         │  WebP）、PDF、Word   │            │
│         │  （.docx）、文本文件  │            │
│         └ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┘            │
│                                           │
└──────────────────────────────────────────┘
```

- 拖入即显示，拖出即消失
- 不支持的文件类型在提示区中红色标注
- 遮罩使用 `bg-ink-black/20 backdrop-blur-sm`

### 2.2 上传队列面板

拖拽松开或点击选择文件后，弹出底部队列面板（非 modal，不阻挡页面）：

```
┌──────────────────────────────────────────┐
│  上传队列 (3 个文件)             [全部上传] │
│                                           │
│  ┌───┬──────────────────────────────────┐ │
│  │ 📷│ 秋招主视觉.png         2.4 MB  ✕  │ │
│  └───┴──────────────────────────────────┘ │
│  ┌───┬──────────────────────────────────┐ │
│  │ 📄│ 品牌手册.pdf           1.8 MB  ✕  │ │
│  └───┴──────────────────────────────────┘ │
│  ┌───┬──────────────────────────────────┐ │
│  │ 📝│ 招生文案.txt             8 KB   ✕  │ │
│  └───┴──────────────────────────────────┘ │
│                                           │
│  ⚠️ 不支持的文件类型                        │
│  旧版设计.doc — .doc 格式暂不支持，请转 .docx │
└──────────────────────────────────────────┘
```

**交互细节：**
- 每个文件可单独移除（✕）
- 不支持的文件自动分到下方警告区，附原因说明
- "全部上传"按钮在无有效文件时 disabled

### 2.3 上传进度

点击"全部上传"后，队列转为进度视图：

```
  正在处理 (2/3)...

  ✅ 秋招主视觉.png — 已完成
  🔄 品牌手册.pdf — 解析中...
  ⏳ 招生文案.txt — 等待中
```

- 处理完的条目自动收起（保留 ✅ 标记 2 秒后消失）
- 失败的条目保留在队列中，显示错误原因 + "重试"按钮
- 全部完成后队列面板自动关闭
- 处理完成的 KnowledgeEntry 即时出现在列表中

### 2.4 文件验证规则

拖拽或选择文件时即时校验：

| 规则 | 行为 |
|------|------|
| 单文件 > 50MB | 红色标记，阻止加入队列 |
| 不支持的类型 | 黄色警告区，阻止上传 |
| 超过 10 个文件 | 提示"一次最多上传 10 个文件"，取前 10 个 |
| 队列为空 | "全部上传"按钮 disabled |
| 全部被拒绝 | 显示拒绝原因 |

### 2.5 与点击上传的关系

- 点击"上传文件"按钮 → 弹出文件选择器 → 选中的文件加入同一队列面板
- 拖拽和点击上传共享完全相同的队列 + 上传逻辑
- `<input type="file" multiple>` 触发方式不同，后续路径统一

## 四、验收标准

- [ ] 拖拽文件到知识库页面出现 drop zone 遮罩 + 提示区

- [ ] 松开后文件加入上传队列面板
- [ ] 队列面板显示文件列表（图标 + 文件名 + 大小），可逐个移除
- [ ] 不支持的文件类型自动分到警告区，附原因
- [ ] 点击"全部上传"开始串行处理，显示实时进度
- [ ] 处理完成后条目即时出现在知识库列表中
- [ ] 超限文件（>50MB / 不支持类型 / >10个）被阻止 + 提示
- [ ] 点击"上传文件"按钮和拖拽上传共享同一套队列逻辑
