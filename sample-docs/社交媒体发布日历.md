# 社交媒体发布日历（模板）

> 在 Mediax 中为每个月份创建"发布计划"，将以下内容条目拆分为具体任务交给 Agent 执行。

---

## 月度内容节奏

建议每月设置 3-4 个内容主题周：

| 周次 | 主题 | 目标 |
|------|------|------|
| 第 1 周 | 行业洞察 / 趋势分析 | 建立专业权威 |
| 第 2 周 | 产品 / 服务深度展示 | 传递核心价值 |
| 第 3 周 | 用户故事 / 案例分享 | 建立信任与口碑 |
| 第 4 周 | 互动话题 / 活动预告 | 提升互动与转化 |

## 状态标记说明

| 标记 | 含义 |
|------|------|
| ✅ 已发布 | 内容已上线 |
| 🎨 设计中 | 视觉素材制作中 |
| 📝 制作中 | 内容创作中 |
| 🎬 拍摄中 | 视频素材拍摄中 |

## 发布检查清单

每篇内容发布前确认：

- [ ] 标题是否吸引点击且准确传达内容？
- [ ] 正文是否有错别字或语病？
- [ ] 配图是否清晰、尺寸是否正确？
- [ ] CTA 或联系方式是否正确可点击？
- [ ] 是否与品牌语气一致？
- [ ] 是否通过了必要的审核？
- [ ] 是否设置了正确的发布时间？
