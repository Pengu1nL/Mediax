# 品牌内容创作指南

## 关于本文档

本文档作为品牌内容创作的统一参考，确保所有渠道输出的内容保持一致的语气、风格和品质。在 Mediax 中创建品牌档案时，请将本文档中的信息填写到对应的品牌字段中，Agent 生成内容时会自动引用。

## 品牌语气

填写到 Mediax 品牌档案的"品牌语气"字段。建议 3-4 个关键词，用顿号分隔。

**示例：** 专业、可信、温暖、有洞察

## 内容红线

填写到"禁用表达"字段。每行列出一条，Agent 会严格避免。

**示例：**
- 避免未经证实的数据或承诺
- 避免贬低竞品或替代方案
- 避免使用绝对化用语
- 避免在非授权渠道发布客户案例

## 各平台内容策略

### 微信公众号

- **定位**：品牌主阵地，深度内容
- **频率**：每周 2-3 篇
- **内容方向**：行业洞察 / 产品更新 / 案例故事 / 创始人专栏
- **标题风格**：信息量大、引人思考，25 字以内
- **配图规范**：封面图 900×383px，正文配图宽度 640px

### 小红书

- **定位**：种草与口碑，贴近目标受众
- **频率**：每周 3-4 篇
- **内容方向**：使用场景 / 开箱体验 / 用户分享 / 行业科普
- **标题风格**：轻松、有情绪、带 emoji
- **配图规范**：3:4 竖版，封面需有文字标题

### 抖音

- **定位**：品牌曝光，触达更广人群
- **频率**：每周 2-3 条
- **内容方向**：产品演示 / 行业观点 / 幕后花絮 / 直播互动
- **配乐建议**：符合品牌调性，不跟风低俗热点

### 视频号

- **定位**：品牌形象，中长视频
- **频率**：每两周 1 条
- **内容方向**：品牌纪录片 / 创始人访谈 / 产品深度测评

## 视觉规范速查

- **品牌色**：主色 + 辅色，填写到 Mediax 品牌设置中
- **字体**：标题用系统黑体，正文用系统苹方/微软雅黑
- **LOGO**：仅使用品牌标准字/标准图形，勿变形、勿更改颜色
- **留白**：保持充足留白，避免信息过密
