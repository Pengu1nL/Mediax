# 建桥融高 品牌内容创作指南

## 品牌定位

建桥融高是一所位于上海临港的民办高中，致力于融合世界先进教育理念，培养具有家国情怀、国际视野、身心健康、学业优异的复合型人才。

## 品牌语气

**专业、可信、温暖、有教育理想。**

- 专业：用数据和事实说话，引用权威教育研究和政策
- 可信：不夸大、不制造焦虑，传递真实可验证的信息
- 温暖：关注学生个体成长，用故事和细节打动人心
- 有教育理想：展现面向未来的教育视野，而非仅仅"考高分"

## 内容红线（严禁触碰）

1. 严禁制造或利用升学焦虑
2. 严禁未经证实的升学承诺或数据
3. 严禁贬低其他学校或教育模式
4. 严禁发布未授权的学生肖像
5. 严禁在文案中使用"保过""包录取""唯一"等绝对化用语

## 各平台内容策略

### 微信公众号

- **定位**：品牌主阵地，深度内容
- **频率**：每周 2-3 篇
- **内容方向**：
  - 校长专栏 / 教育理念深度文章
  - 招生政策官方解读
  - 校园活动报道
  - 优秀学子故事
- **标题风格**：信息量大、引人思考，25 字以内
- **配图规范**：封面图 900×383px，正文配图宽度 640px

### 小红书

- **定位**：种草与口碑，贴近年轻家长
- **频率**：每周 3-4 篇
- **内容方向**：
  - 校园环境打卡（建筑、设施、食堂）
  - 社团活动花絮
  - 学生日常 vlog 式图文
  - "在读家长说"系列
- **标题风格**：轻松、有情绪、带 emoji
- **配图规范**：3:4 竖版，封面需有文字标题

### 抖音

- **定位**：品牌曝光，触达更广人群
- **频率**：每周 2-3 条
- **内容方向**：
  - 校园实拍短视频（15-60 秒）
  - 教育话题观点分享
  - 直播（招生季每周一次）
- **配乐建议**：轻快、温暖、不过度炫技

### 视频号

- **定位**：品牌形象，中长视频
- **频率**：每两周 1 条
- **内容方向**：
  - 校园纪录片风格视频
  - 名师访谈
  - 教学成果展示

## 视觉规范速查

- **品牌色**：信号橙 `#F37338` / 墨黑 `#1A1A1A`
- **辅助色**：浅橙 `#FF8C5A` / 石板灰 `#6B7280`
- **字体**：标题用系统黑体，正文用系统苹方/微软雅黑
- **LOGO**：仅使用品牌标准字，勿变形、勿更改颜色
- **留白**：保持充足留白，避免信息过密
