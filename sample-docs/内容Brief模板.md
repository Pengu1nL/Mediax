# 内容 Brief 模板

> 在 Mediax 中创建任务时，按此模板填写 Brief 字段，Agent 将以此为依据生成内容。

---

## 基本信息

| 字段 | 内容 |
|------|------|
| **任务标题** | 简明扼要地描述任务 |
| **发布渠道** | 微信公众号 / 小红书 / 抖音 / 视频号 / 官方博客 |
| **内容类型** | 图文 / 短视频 / 直播 / 长文章 / 海报 |
| **计划发布时间** | YYYY-MM-DD HH:MM |

## 内容目标

- **核心目标**：这次内容要实现什么？
- **成功指标**：用什么数据衡量效果？

## 目标受众

- **主要受众**：谁会看到这条内容？
- **受众痛点**：他们关心什么问题？
- **受众期待**：他们希望获得什么信息？

## 核心信息

1. **必须传达的关键信息**
2. **次要信息点**
3. **希望受众记住的一句话**

## 内容要求

- **语气要求**：专业 / 温暖 / 轻松 / 权威
- **字数/时长要求**
- **必须包含的元素**：如 CTA 按钮、二维码、联系方式
- **禁止出现的表达**
- **参考内容链接**

## 素材清单

- [ ] 封面图
- [ ] 正文配图
- [ ] 数据图表（如需要）
- [ ] 视频素材（如需要）
- [ ] Logo / 品牌标识

## 调研指令

供 Agent 执行调研时参考：需要了解哪些背景信息？有哪些关键词可以搜索？

## 审核链路

- [ ] 内容作者自检
- [ ] 品牌负责人审核
- [ ] 终审发布
